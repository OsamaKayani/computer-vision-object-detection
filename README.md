# Computer Vision Object Detection Utilities

Small, dependency-free building blocks for inspecting object-detection output: bounding-box validation, intersection over union and confidence-ordered non-max suppression.

```bash
python -m pip install -r requirements.txt
pytest -q
```

The repository intentionally contains no employer or thesis dataset, imagery or trained weights. These utilities are original portfolio-safe examples inspired by general YOLO/OpenCV work.
